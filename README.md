# Pingo

QQ에서 영감을 받은 파란색 테마의 채팅 앱입니다. 이메일 회원가입·로그인은 서버에서 처리하며, 채팅은 브라우저에 저장하는 데모입니다.

## 실행

**Node.js 24 이상**이 필요합니다. 외부 패키지 설치 없이 Node.js 내장 SQLite를 사용합니다.

```sh
npm start
```

기본 포트는 3000입니다. 다른 서버가 사용 중이면 `PORT=3001 npm start`로 실행하세요.

## 계정 사용

1. 첫 화면에서 **회원가입**을 선택합니다.
2. 이름(1~30자), 이메일, 비밀번호(10~128자), 비밀번호 확인을 입력합니다.
3. 가입 후 자동 로그인되며, 왼쪽 아래 로그아웃 버튼으로 종료할 수 있습니다.
4. 이메일·비밀번호로 다시 로그인할 수 있고, 로그인 세션은 7일 동안 유지됩니다.

- 계정과 세션은 `.data/pingo.sqlite`에 저장됩니다. 서버 재시작 후에도 유지됩니다.
- `PINGO_DB_PATH`로 데이터베이스 파일 경로를 지정할 수 있습니다. 배포 환경에서는 영구 볼륨을 사용하고 백업하세요.
- 데이터베이스, 세션, `.env` 파일은 Git에 저장하지 않습니다.
- 비밀번호는 무작위 salt와 scrypt로 해시하고 세션 토큰도 해시로 저장합니다.
- 쿠키는 HttpOnly·SameSite=Lax이며, 외부 사이트의 인증 변경 요청을 차단합니다.
- 가입·로그인은 IP당 15분 동안 30회로 제한됩니다. 메모리 기반 제한은 서버 재시작 시 초기화되며, 프록시 환경에서는 여러 사용자가 같은 제한을 공유할 수 있습니다.
- 공개 배포 시 HTTPS를 사용하고 `COOKIE_SECURE=true`로 실행하세요. 이 설정은 Secure 쿠키와 `__Host-` 쿠키 이름을 사용합니다.

## 채팅 기능과 범위

- 친구 검색·추가, 대화 전환, 메시지 전송, 이모지, 모바일 화면 지원
- 대화는 **사용자 ID별로 구분한 localStorage**에 저장하며 계정의 서버 데이터베이스에는 저장하지 않습니다.
- 이전 비로그인 데모의 `pingo-v1` 데이터는 특정 계정에 자동 연결하지 않습니다.
- 같은 브라우저 프로필을 사용하는 사람은 개발자 도구에서 로컬 대화 데이터에 접근할 수 있습니다. 대화 저장소 분리는 서버 권한 제어를 대체하지 않습니다.
- 실제 사용자 간 통신, 이메일 소유 확인, 비밀번호 재설정, 소셜 로그인, 파일 전송은 아직 구현하지 않았습니다.
- Google Fonts에 연결할 수 없으면 시스템 글꼴로 동작합니다.

## 검증

```sh
npm run check
npm test
```

통합 테스트는 임시 SQLite와 별도 서버를 사용하며, 회원가입·중복 가입·로그인·로그아웃·세션 복원·만료·잘못된 요청 차단·시도 횟수 제한을 검증합니다. 실제 계정 데이터는 변경하지 않습니다.
