# Pingo

QQ에서 영감을 받은 파란색 테마의 반응형 채팅 UI 데모입니다.

## 실행

Node.js 20 이상에서 추가 의존성 설치 없이 실행합니다.

```sh
npm start
```

기본 포트는 3000이며 `PORT` 환경 변수로 변경할 수 있습니다.

## 기능

- 대화 전환, 친구 검색, 새 친구 추가
- 메시지 전송, 이모지 선택, 줄바꿈
- 브라우저 localStorage에 대화 저장
- 모바일 대화 목록과 대화창 전환

실제 사용자 간 통신, 로그인, 온라인 상태, 파일 전송은 구현되어 있지 않습니다. 기본 대화는 예시 데이터이며 메시지는 서버로 전송되지 않습니다. 외부 Google Fonts에 연결할 수 없어도 시스템 글꼴로 동작합니다.

## 기본 검증

```sh
npm run check
```
